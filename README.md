# Señas que enseñan

OVA de preparación docente en Lengua de Señas Colombiana y estrategias inclusivas para Ciencias Naturales, adaptable a computador, tableta y celular.

## Publicar

Sube **todo el contenido** de este paquete a la raíz del repositorio. Activa **Settings → Pages → Deploy from a branch → main → /(root)**.

No subas únicamente el ZIP ni dejes `index.html` dentro de una carpeta adicional.

Consulta [GUIA_PUBLICACION.md](GUIA_PUBLICACION.md) para los pasos completos y [FUENTES_Y_ALCANCE.md](FUENTES_Y_ALCANCE.md) para atribuciones y límites del recurso.

## Experiencias

- Ruta introductoria y decisiones docentes con retroalimentación.
- Repertorio de 61 señas y expresiones de fuentes educativas.
- Búsqueda, filtros, favoritas y registro de práctica.
- Misiones de Ecosistemas, La célula, Estados de la materia y Primeras señas, con pistas y sugerencias para el aula.
- Taller guiado de siete pasos con retos que conduce a un borrador de clase.
- Mediateca y kit imprimible.
- Ajustes de lectura y modo enfoque.
- Respaldo y recuperación voluntaria del avance para cambiar de dispositivo.

## Requisitos

Un navegador moderno con JavaScript. No requiere compilación, dependencias ni servidor de aplicaciones. Los videos y fuentes externas requieren internet. El avance se guarda en cada navegador.
